# QA-Automation-Web-Saucedemo-selenium-ts 
URL: https://www.saucedemo.com/

## Setup
Make sure to have the following installed program on your system:
- **Node.js** (v18 or higher recommended)
- **npm**
- **Google Chrome** and/or **Mozilla Firefox**

then follow these code:

```bash
git clone https://github.com/ArChierz/QA-Automation-Web-Saucedemo-selenium-ts.git
cd QA-Automation-Web-Saucedemo-selenium-ts
npm install
npm run test:chrome
npm run test:firefox
npm run report
```

Headless:

```bash
npm run test:chrome-report
npm run test:firefox-report
```

To start contribute:

```bash
git checkout -b feature/feature-name
```
